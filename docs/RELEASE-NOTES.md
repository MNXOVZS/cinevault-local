# v1.8.0-preview · 首次公开预览

映库 CineVault Local 是用于本机视频和照片的影音资料库。此预览版提供源码和启动脚本。安装 Python 和 FFmpeg 后，可以启动应用并登记现有目录。

## 可体验的功能

- 关联硬盘目录，保留原有文件位置。
- 用封面、静音卡片预览和搜索浏览资料。
- 点击封面标签筛选，以时间轴抽样图定位画面。
- 查看来源扫描、文件变动和登记数量。
- 手动备份片目、封面和已登记预览。
- 可选安装 Qwen3-VL 2B，在本机生成画面概述和语义标签。

## 发布范围

此版本使用系统 Python 和 FFmpeg。视觉概述的权重与运行组件由可选脚本下载。ONNX 分类和语音活动检测组件未包含在源码包内。视频播放、静音预览和时间轴依赖浏览器及本机 FFmpeg。

源码包在 Windows 验证。macOS 提供启动脚本，实机验证待完成。安装命令见 [README](../README.md)。

仓库内图片用于功能演示。封面源自 AI 生成的原创插画，样片和示例标签为演示制作。原创源码采用 [MIT 许可证](../LICENSE)，第三方下载项沿用上游许可。
